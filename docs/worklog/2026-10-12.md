## 聊天服务器启动（Windows 侧联调）
- 登录凭据：`server/chat_server.c` 写死 —— 账号 `admin` / 密码 `1234`，端口 `8888`。
- 服务器是纯 Linux/POSIX 程序（`sys/socket.h` + `pthread`），**Windows 本机不能直接跑**，必须经 WSL。
- 启动方式（WSL Ubuntu，已装 gcc）：
  ```bash
  wsl.exe bash -lc "cd /mnt/c/Users/yanji/Desktop/yan/smartterm/server && gcc chat_server.c cJSON.c -o chat_server -lpthread && nohup ./chat_server > /tmp/chat_server.log 2>&1 & disown"
  wsl.exe bash -lc "ss -ltnp | grep 8888"     # 验证监听
  wsl.exe bash -lc "pkill -f chat_server"     # 停止
  ```
- 已实测：WSL 内 `127.0.0.1:8888` 登录 admin/1234 → 返回 `{"status":"success","message":"welcome","data":{"id":1,"name":"admin"}}`。
- ⚠️ 板端客户端连 `127.0.0.1:8888`，**服务器必须也跑在板子上**（用已交叉编好的 `server/chat_server_arm`）；
  本机 WSL 实例只用于 PC 侧联调，板子回连本机需走 Windows 主机 LAN IP。

## 上板调试：2048 滑动 + music 按钮两个 bug（已改代码，待复验）

### 现象
1. **2048**：进游戏后滑动不能移动数字，变成整个游戏/画面在平移。
2. **music**：页面上所有按钮点击无效，连 **BACK 都按不了**，只能 Ctrl+C 结束进程。

### 根因
- **bug1**：`board_obj = lv_obj_create(...)` 的容器**默认带 `LV_OBJ_FLAG_SCROLLABLE`**；格子坐标又多算一重 pad 偏移、内容比内容区大 8px → 容器真可滚动。手指一滑，LVGL 判定为"滚动容器"并**抢走 press（发 `LV_EVENT_PRESS_LOST`）**，自己的 `PRESSED/RELEASED` 手势回调收不到完整事件 → 方块不动、只有画面平移。
- **bug2**（两因素叠加）：
  - ① music/home/2048 入口**没清 screen 的滚动标志**（只有登录页清了），触摸抖动超 `scroll_limit`（默认仅 10px）就被误判成滚动 → `CLICKED` 永不触发 → 按钮全失灵；
  - ② `mplayer_stop()` 里 **`waitpid(pid,NULL,0)` 无限阻塞**：mplayer 不响应 fifo 的 `quit` 时整个 LVGL 主线程冻结 → "所有按钮点不动只能 Ctrl+C"。

### 修复（4 个文件）
| 文件 | 改动 |
| --- | --- |
| `main.c` | `#include "lvgl/src/indev/lv_indev_private.h"`；`indev->scroll_limit = 25;` |
| `game_2048.c` | 清 screen/棋盘/格子/遮罩的 `SCROLLABLE`（格子另清 `CLICKABLE`）；格子坐标去掉 pad 偏移；手势改到 **`LV_EVENT_PRESSING` 阶段判定** + 处理 `PRESS_LOST` |
| `app_music.c` | 清 screen/top/ctrl_bar 的 `SCROLLABLE`；`mplayer_stop()` 改 **300ms 轮询 + SIGKILL 兜底**（SIGKILL 后也有界回收）；视频自然播完补关 fifo + 复位当前曲目；新增视频看门狗 `VIDEO_MAX_MS=10min`；关键回调加 `[MUSIC] ...` 日志 |
| `ui_home.c` | 清 screen/卡片的 `SCROLLABLE` |

### 独立复核结论（只读 review）
- 2048 修复判定为**正确**；
- music 原修复只覆盖一半，据此补充 3 点：① `mplayer_stop` 里 SIGKILL 后仍阻塞 `waitpid` → 改有界轮询；② 视频自然播完未收尾 fifo / 未复位当前曲目 → 已补；③ 新增视频看门狗；
- 次要建议（已采纳）：`scroll_limit` 由 40 调为 25（过大让列表滚动迟钝）；遮罩/卡片统一清滚动标志。
